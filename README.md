## Para actualizar GitHub Pages

Subir el contenido de esta carpeta a la raíz del repositorio, reemplazando los archivos actuales.

La URL principal debe seguir siendo la misma; por tanto, el QR impreso no necesita cambiar.

## Criterio de interfaz

Explorador 1 y Explorador 2 usan la misma interfaz, tablero, inspector de coordenadas,
animaciones, progreso, Play/Replay y retroalimentación. Entre ellos cambia el contenido
matemático: gráfica, puntos relevantes y valores de x que se analizan.
